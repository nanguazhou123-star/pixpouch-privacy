# 图小匣图片压缩：微信小程序说明

图小匣图片压缩是一款微信小程序，用于把单张照片调整到指定文件体积，修改像素宽高，并输出JPG。本目录介绍微信小程序的用法与限制，不适用于图小匣Windows版软件。

## 在微信中找到工具

打开微信搜一搜，切换到“小程序”，搜索完整名称“图小匣图片压缩”。是否出现、名称和入口信息均以微信当时显示的结果为准。

## 按上传要求处理照片

先看清上传方要求的文件体积、像素和格式，再选择一张JPG或PNG图片。设置KB上限；若有固定宽高，再填写像素并检查裁剪位置。处理后核对实际文件大小、像素和格式，放大查看细节，再选择保存。

体积快捷项有20KB、30KB、50KB、100KB和200KB，也可自定义1–10240KB；本工具按1KB＝1000字节计算。输出宽高支持32–4096的整数像素，总像素最多1200万；比例不同时裁剪，不拉伸。输出为JPG，透明区域填成白色。

## 图片处理与授权

用户同意后，图片副本需要联网发送至微信内容安全服务检测；通过后才在本机裁剪、压缩。保存到相册需要相册授权，无需注册本工具的业务账号。文件体积、像素及格式符合要求，不代表背景、构图等报名条件也合格。
