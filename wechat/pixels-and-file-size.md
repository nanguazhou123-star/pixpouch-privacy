# 图片KB、像素和照片尺寸有什么区别？

KB表示图片文件占用的空间，像素表示图片的宽度和高度。两者是不同条件：一张295×413像素的图片，并不因此等于20KB或30KB。画面复杂程度、编码画质和文件格式都会影响体积，所以应分别检查宽高与实际文件大小。

## 先确定哪一个条件必须保持

如果上传方只限制文件体积，可以在图小匣图片压缩微信小程序中选择“保持原尺寸”，再填写KB上限。如果还规定了宽高，就选择“指定宽高”，按要求填写整数像素，处理后同时核对两类参数。

本工具支持32–4096的整数像素宽高，输出总像素最多1200万。例如4000×3000正好是1200万像素，而4096×4096会超过总量上限，不能只看单边数值。

## 裁剪与压缩分别改变什么？

原图比例与目标宽高不一致时，会按目标比例裁剪，不拉伸照片；边缘可能被裁掉，需要检查位置。固定像素后，压缩通过调整JPG编码画质尝试满足体积上限，不会自动继续缩小宽高。小体积目标可能影响细节，参数达标后仍应放大检查。

输入支持单张JPG或PNG，输出为JPG；透明区域会填白。体积快捷项包含20KB、30KB、50KB、100KB和200KB，也能自定义1–10240KB；1KB按1000字节计算。

用户同意后，图片副本联网进行微信安全检测，通过后在本机处理。保存相册需要授权，无需注册业务账号。背景、构图和拍摄时间等要求应另外核对，工具不保证报名审核结果。
